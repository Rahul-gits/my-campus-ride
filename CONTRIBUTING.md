# Contributing to Campus Ride Management System

Thank you for considering contributing to Campus Ride Management System! We welcome community contributions, bug fixes, feature requests, and improvements.

## 🚀 How to Contribute

1. **Fork the Repository**
   Click the **Fork** button at the top right of the [GitHub Repository](https://github.com/Rahul-gits/my-campus-ride) to create your own copy.

2. **Clone Your Fork**
   ```bash
   git clone https://github.com/YOUR-USERNAME/my-campus-ride.git
   cd my-campus-ride
   ```

3. **Create a Feature Branch**
   ```bash
   git checkout -b feature/my-new-feature
   ```

4. **Make Your Changes & Verify**
   - Follow the existing code style (React, TypeScript, Tailwind CSS, Node.js).
   - Ensure there are no compilation errors:
     ```bash
     npx tsc --noEmit
     ```
   - Test locally by running both frontend and backend dev servers.

5. **Commit Your Changes**
   Use clear and descriptive commit messages following standard conventions:
   ```bash
   git commit -m "feat: add real-time bus telemetry websocket listener"
   ```

6. **Push and Open a Pull Request**
   ```bash
   git push origin feature/my-new-feature
   ```
   Navigate to the original repository on GitHub and click **New Pull Request**.

## 📜 Code Style & Quality Standards

- Maintain documentation and docstrings where applicable.
- Ensure TypeScript types are explicitly declared without using `any` unnecessarily.
- Maintain responsive, accessible UI layouts with modern dark/light mode aesthetics.
